# Phase H8-R2BE：Source-binding hash persistence 计划

## 背景

H8-R2BD 证明 checkpoint discovery shadow 可以安全地从
`RuntimePromptContextSnapshot.compaction_bindings` 发现 reusable compaction identity，但当前
`ContextCompactionBinding` 没有保存当时 source candidates 的 body-free binding hash。为了避免把当前
prompt payload 现算 hash 后伪装成旧事实，BD 要求外部提供 `source_binding_hash` index；缺失时
fail closed。

这使 checkpoint discovery 仍然半自动。下一步应把 source-binding hash 持久化到现有
`ContextCompactionBinding`，让 checkpoint prompt snapshot 自身携带足够的 body-free source drift
证据。

## 目标

1. 扩展现有 `ContextCompactionBinding`，增加可迁移的 `source_binding_hash` 字段。
2. 新增统一的 body-free source-binding hash 计算函数，覆盖候选身份、source identity、role、
   retention/trust/freshness/truncation/source_order 和 content hash。
3. `MemoryContextBuilder` 新生成的 compaction binding 必须写入 `source_binding_hash`。
4. H8-R2BD checkpoint discovery helper 优先使用 binding 自带 hash；外部 map 只作为历史 binding
   兼容输入。若两者都存在但不一致，fail closed。
5. 保持 shadow-only：不启用 prompt use，不读取 artifact body，不改变 request/prompt/selection identity。

## 非目标

- 不新增 public metadata contract。
- 不启用 reusable summary prompt-use。
- 不修改 compaction record artifact body；artifact body 仍是 `ContextCompactionRecord`。
- 不自动做语义质量判定或真实收益声明。

## Metadata impact note

Fact:
A prompt-bound context compaction binding can persist the body-free hash of the exact source candidate view it replaced.

Authoritative producer:
`MemoryContextBuilder` when it creates a new `ContextCompactionBinding` after the compaction artifact sink succeeds.

Consumers:
Checkpoint discovery shadow helper, runtime prompt snapshot replay checks, tests/receipts, future prompt-use design.

Lifecycle:
Checkpoint / prompt-context snapshot nested value. Historical bindings may omit the field.

Control impact:
Recovery and future reuse admission. In this phase it controls only shadow admission/rejection, not prompt content.

Existing contracts reviewed:
`ContextCompactionBinding`, `ContextCompactionRecord`, `DurableArtifactReference`,
`RuntimePromptContextSnapshot`, `ContextCompactionReuseAdmission`,
`MemoryContextBuilder`, `memory.compaction_summary`, `memory.compaction_reuse`,
`CONTRACT_CATALOG.md`, `API.md`, `docs/metadata/DEVELOPMENT_CONVENTIONS.md`.

Decision:
Extend existing `ContextCompactionBinding`; do not create a new contract. The fact belongs to the binding lifecycle
because it binds a compact record/artifact to the exact source projection view replaced in that prompt context.

Why no duplicate source of truth is created:
`ContextCompactionRecord.source_fingerprint` remains the summary source-content fingerprint. The new
`source_binding_hash` is a different body-free projection guard used for reuse drift checks. When both persisted and
external hash inputs exist, persisted binding hash is authoritative and conflicts reject.

Serialization and migration:
Field defaults to an empty string for historical checkpoints/receipts. New producers write a `sha256:` hash. Consumers
must treat empty as missing and fail closed unless a caller explicitly supplies a historical compatibility hash.

Tests:
Metadata round-trip/default migration, hash helper stability, builder-generated binding carries hash, checkpoint
discovery uses binding hash without external map, conflict with external map rejects, historical missing hash still
rejects unless supplied externally.

Documentation updates:
H8-R2BE result doc, API, contract catalog, evidence index, completion audit, implementation log.

## 实施计划

1. Add `source_candidate_binding_hash(...)` to `memory.compaction_summary` and test that it matches the existing
   shadow-payload-derived hash.
2. Extend `ContextCompactionBinding` with `source_binding_hash: str = ""` and validation for empty-or-SHA256.
3. Update `MemoryContextBuilder` binding creation to persist the hash for `record.source_candidate_ids`.
4. Update `memory.compaction_reuse`:
   - `ReusableCompactionArtifactCandidate.from_binding(...)` can use persisted hash by default;
   - checkpoint discovery provider uses binding hash first;
   - external map conflict rejects as `artifact_contract_invalid`;
   - empty historical hash still fail closed unless supplied.
5. Add H8-R2BE experiment harness and receipt.
6. Run focused metadata/context/experiment gates and update evidence.

## 通过标准

- New bindings generated by `MemoryContextBuilder` carry non-empty `source_binding_hash`.
- Historical bindings without the field still parse.
- Checkpoint discovery admits from persisted binding hash with no external index.
- Missing historical hash rejects; supplied historical hash admits; conflict rejects.
- Prompt/request/selected candidate/context compaction identity remains unchanged except for the new binding field.
- Receipts contain no prompt/source/summary body or secrets.
